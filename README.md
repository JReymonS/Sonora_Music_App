# Sonora App

Sonora es una aplicación web para escuchar música y podcasts: explora playlists, busca canciones y reprodúcelas desde una barra siempre visible.

# Como instalar y configurar entorno local:

Ejecutar una terminal en donde se encuentra tus proyectos y escribir:

- git clone [https://github.com/JReymonS/Sonora_Music_App.git] (https://github.com/JReymonS/Sonora_Music_App)

También deberá instalar dependecias de PHP y Node:

- composer install
- npm install

Configurar las variables de entorno:

- cp .env.example .env
- php artisan key:generate

# Como ejecutar:

Para poder ejecutar el proyecto, debemos tener Herd en ejecución y ejecutar en consola el comando:

- npm run dev
